# 시작하기

BIBIM은 자연어를 Revit 작업으로 바꿔줍니다 — 하고 싶은 걸 말로 설명하면 BIBIM이 C#을 작성·검증·실행합니다. 이 가이드는 설치부터 첫 명령 성공까지를 안내합니다.

## 1. 설치

1. [Releases 페이지](https://github.com/SquareZero-Inc/bibim-revit/releases)에서 최신 인스톨러를 받습니다 (한국어는 `_kr`, 영어는 `_EN` 빌드).
2. Revit을 종료한 뒤 인스톨러를 실행합니다. 감지된 모든 Revit 버전(2022–2027)에 BIBIM이 자동 등록됩니다.
3. Revit을 엽니다. 리본에 **BIBIM AI** 탭이 생깁니다 — 클릭하면 패널이 열립니다.

## 2. 무엇으로 구동할지 고르기

BIBIM은 **내 키로 직접(BYOK)** 동작합니다: *내* 자격증명으로 LLM에 직접 연결하며, 구독이 없고 어떤 데이터도 우리에게 전송하지 않습니다. 구동 방법은 무료부터 프리미엄까지 세 가지입니다.

### 옵션 A — 로컬 모델 실행 · API 키 없음, 비용 없음

API 키를 다루고 싶지 않다면, 내 PC에서 도는 모델을 BIBIM이 가리키게 하면 됩니다.

- Ollama, LM Studio, vLLM, llama.cpp 등 OpenAI 호환 엔드포인트를 제공하는 무엇이든 동작합니다.
- 키도, 질의당 비용도 없고, 어떤 것도 PC 밖으로 나가지 않습니다.
- 전체 단계: **[로컬 모델로 실행](./local-llm)**.

### 옵션 B — Google Gemini · 가장 저렴한 클라우드, 무료 티어로 시작

- [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 키를 발급받습니다. Google AI Studio는 시작용 무료 티어가 있습니다.

### 옵션 C — Claude 또는 GPT · 최고 품질

- 권장 기본값: **Claude Sonnet 4.6**. 그 외 Claude Opus 4.7, OpenAI GPT-5.5 사용 가능.
- 단계별 키 발급(계정 → 결제 → 키): **[Anthropic / OpenAI 키 발급 가이드](https://squarezero.notion.site/BIBIM-API-Key-34fa486f5e6d807cb307fdd08459b92d)**.
- 전형적인 질의 비용은 몇 센트 수준입니다. Anthropic 최소 충전 $5면 일상적인 질의 수백 회를 감당하며, 설정 패널에 모델별 예상 비용이 실시간 표시됩니다.

::: warning 키는 안전하게
API 키는 비밀번호처럼 다루세요 — 공유하거나 소스 저장소에 올리지 마세요.
:::

## 3. 자격증명 입력 후 모델 선택

1. BIBIM 패널에서 톱니바퀴(⚙) 아이콘을 눌러 **설정**을 엽니다.
2. 해당 프로바이더 칸에 키를 붙여넣습니다 — 로컬 모델이라면 서버 URL을 입력합니다([로컬 모델로 실행](./local-llm) 참고). **저장**을 누릅니다.
3. 선택기에서 모델을 고릅니다. 키가 없는 모델은 비활성화되며, 어떤 키를 추가해야 하는지 툴팁이 안내합니다.

## 4. 첫 명령

자연어로 요청을 입력해 보세요. 예:

> 레벨 1의 모든 문을 선택해서 순서대로 이름을 바꿔줘.

BIBIM은 다음을 수행합니다:

- 작업을 단계로 나누고 필요한 확인 질문을 하며,
- C#을 생성·검증합니다 — 모델에 손대기 전에 Roslyn 안전 게이트가 먼저 돕니다,
- 미리보기를 보여줍니다 (**드라이런**으로 영향받는 요소를 먼저 확인),
- 실행하고, 적용된 변경은 **되돌리기** 한 번으로 취소할 수 있습니다.

이걸로 첫 BIBIM 명령 완료입니다. 완전히 키 없이 쓰려면 **[로컬 모델로 실행](./local-llm)**을 이어서 읽어보세요.
