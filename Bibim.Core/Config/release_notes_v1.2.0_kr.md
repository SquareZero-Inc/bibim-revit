# BIBIM v1.2.0

**릴리즈일**: 2026-10-04

> **메이저 기능 릴리즈** — 최신 모델 세대 지원, Gemini 제거, 하네스 정직성·비용·속도 전면 개선, 보안 강화, .NET 10 대응.

---

## 한 줄 요약

**Claude Sonnet 5 / Opus 5.5 / Fable 5.1과 GPT-6를 쓸 수 있고, "되는 척"이 사라졌다. 안 되는 요청은 바로 말하고, 적용 결과는 실측으로 보고하고, 코드 생성 중에는 무엇을 하는지 실시간으로 보여준다. 단순 조회는 코드 없이 초 단위로 답한다.**

---

## ⭐ 새 기능

- **문서 첨부**: 입력창의 클립 버튼(또는 끌어다 놓기)으로 `.md` · `.txt` · `.csv` 파일 1개를 첨부해 지시할 수 있습니다. 예: 모델 검토 결과 표를 첨부하고 "이 문서의 위반 요소를 규칙에 맞게 수정해 줘". ElementId/UniqueId 열이 있는 표는 자동으로 대상 목록을 뽑아 계획 전에 "대상 요소 N건, 규칙 X" 요약을 보여주고, 미리보기·적용 결과에 "목록 밖 변경 0건" 대조 줄을 붙입니다. 문서 본문은 AI 요청에만 쓰이고 세션 기록·로그에는 저장되지 않습니다.
- **[다시 실행] 버튼**: 완료된 작업 카드에서 같은 코드를 현재 모델·선택 상태로 다시 미리보기할 수 있습니다. 요소를 선택하지 않고 실행했을 때 처음부터 다시 요청할 필요가 없습니다.

## 🐛 버그 수정

- **잘못된 버전 경고 제거**: `Element.LevelId`, `Parameter.AsInteger()`를 "Revit 2024에서 제거됨"으로 잘못 표시하고 자동으로 바꿔 쓰던 문제를 고쳤습니다(두 API는 2024·2026에서 그대로 존재). `ElementId.IntegerValue`는 2024에선 경고, 2026에선 오류로 정확히 구분합니다. 워크셋 코드(`WorksetId.IntegerValue`)를 망가뜨리던 자동 수정도 고쳤습니다.
- **생성 코드 컴파일 오류 감소**: `System.IO`·`System.Text`를 기본으로 포함해 `Path`·`File`·`StringBuilder` 오류가 사라졌습니다.
- **실행 버튼이 안 보이던 문제**: 결과가 길면 작업 카드가 입력창과 버튼을 화면 밖으로 밀어내던 문제를 고쳤습니다(카드 안에서 스크롤). 치수선 작성 같은 쓰기 요청이 "모델 요약"으로 잘못 처리되어 아무것도 하지 않고 완료되던 문제, 수정·생성 작업이 조회로 분류되어 [실제 적용] 버튼이 생기지 않던 문제도 고쳤습니다.
- **경사로(Ramp)**: Revit API에는 경사로를 만드는 기능이 없습니다. 이제 편집할 수 없는 DirectShape로 흉내 내지 않고, 먼저 그 사실을 알린 뒤 같은 치수의 **Slope Arrow 경사 바닥**을 제안합니다.
- **그리드 2D 설정 복사**: 한 뷰의 그리드 길이·끝점·2D/3D 설정을 다른 뷰에 적용할 때 버블만 바뀌던 문제를 고쳤습니다(`PropagateToViews` 사용).
- **난치수 치수 검토**: 2345.000 같은 정상 치수까지 난치수로 잡아 치수선을 수천 개 만들던 문제를 고쳤습니다. 허용 자릿수를 한 번 묻고, 인접한 평행 요소끼리만 검토하며, 200개 넘게 생성될 때는 만들지 않고 보고합니다. 미리보기에서도 새 요소가 200개 이상이면 경고합니다.
- **설치 파일 서명**: 설치 파일 안의 DLL이 서명되지 않거나 잘못된 인증서로 서명되어 Revit에서 "서명 오류" 경고가 뜨던 빌드 문제를 고쳤습니다.

## ⭐ 하네스: "되는 척" 제거

- **불가능한 요청은 즉시 안내**: 리본 버튼·패널 UI·타 애드인 제어처럼 실행 중인 세션에서 원천적으로 불가능한 작업은 코드 생성 없이 바로 이유와 대안을 알려줍니다. (이전: 몇 분짜리 코드 생성 후 실패)
- **적용 후 실측 검증**: [실제 적용] 후 완료 메시지에 **[검증]** 블록이 붙습니다 — 실제 변경된 요소 수(추가·수정·삭제), 미리보기 예측과의 차이, 코드가 보고한 파일이 디스크에 실제로 있는지. 모델 변경 작업인데 아무것도 안 바뀌었으면 ⚠로 알려줍니다.
- **미리보기 문구 실측화**: "미리 검증 완료 — 변경 예정 요소 N개" / "변경 없음(파일·뷰 작업이면 정상)".
- **작업 유형을 구조적으로 판단**: 플래너가 작업 유형(조회·내보내기·모델 수정·생성·삭제·뷰/선택·주석)을 구조화된 필드로 내보내, 키워드 추측으로 인한 오판(예: 내보내기를 "0개 변경 실패"로 오인해 재생성)이 줄었습니다.
- **플래너 실패 시 안전 정지**: 계획 단계가 실패하면 모델을 바꾸는 요청은 확인 없이 실행하지 않고 멈춥니다.
- **작업 간 코드 혼선 제거**: 작업 A 카드에서 [실제 적용]을 누르면 항상 A의 코드가 실행됩니다. 작업은 생성 시점의 문서에 묶입니다.
- **미리보기↔적용 사이 선택 유실 수정**.

## ⭐ 속도·가시성

- **코드 보관함 재사용**: 비슷한 작업이면 모델이 저장된 스니펫을 먼저 검색해 검증된 코드를 고쳐 씁니다(실행 전 검증 절차는 동일).
- **단순 조회는 코드 없이**: "2층 문 몇 개야?" 같은 질문은 새 조회 도구(`count_elements`, `list_elements`)로 바로 답합니다. 합계·면적처럼 계산이 필요하면 기존처럼 코드를 작성합니다.
- **코드 생성 실시간 진행 표시**: 진행 배너에 모델이 지금 무엇을 생각·작성 중인지 한 줄로 표시하고, "(3/15)" 단계 카운터가 붙습니다. 몇 분짜리 대기가 더 이상 멈춘 화면처럼 보이지 않습니다.
- 계획 단계에도 "요청 분석 중..." 배너, 상태 문구 한국어화, 트레이 알림은 질문·오류·미리보기 완료 때만.

## 비용

- **프롬프트 캐시 1시간 유지**: 시스템 프롬프트·도구 정의는 1시간, 대화 꼬리는 5분 캐시. 드라이런이 길거나 사용자가 잠시 자리를 비워도 캐시가 유지됩니다.
- **대화 이력 계단식 윈도우**: 매 턴 이력이 한 칸씩 밀려 캐시가 깨지던 문제를 해결했습니다.
- **구간별 effort 제어**: 계획 low · 일반 대화 medium · 코드 생성 high (설정 파일 `llm` 항목으로 조정 가능).
- 토큰 표시는 캐시 포함 실처리량 기준으로 통일.

## 사용성

- **한글 입력 Enter 버그 수정**: 한글 조합 중 Enter가 전송되던 문제를 모든 입력란에서 수정.
- **마크다운 렌더링**·C# 코드 하이라이트, 메시지 복사 버튼.
- **오류 메시지 정리**: `Anthropic API 401: {json}` 같은 원문 대신 "API 키를 확인해 주세요" 같은 행동 안내.
- 질문 카드가 입력창을 가리지 않음("채팅으로 답할게요" 출구), 좁은 도크에서 사이드 패널 겹침 해결, 스크롤 위치 유지, 작업 취소 2단계 확인, 패널 멈춤 자동 복구.

## 보안·감사

- **API 키 암호화 저장**: `rag_config.json`의 키를 Windows DPAPI(현재 사용자)로 암호화합니다. 기존 평문 키는 첫 실행 때 자동 암호화됩니다.
- **로컬 감사 로그**: 모든 적용·되돌리기가 `%APPDATA%\BIBIM\audit\audit_YYYYMM.jsonl`에 기록됩니다(문서, 모델, 변경 요소 ID, 코드 해시, 검증 결과, 위험도). 외부로 전송되지 않습니다.

## 플랫폼

- **Revit 2025.5 / 2026.5(.NET 10) 대응**: 사용하지 않던 Anthropic SDK·Markdig 패키지를 제거해 호스트와의 어셈블리 충돌 여지를 줄였습니다.
- Revit 2027 DLL도 코드 서명.

## 업데이트 시 참고

- **자동 마이그레이션**: Gemini 선택 → Claude Sonnet 5, 평문 키 → 암호화 (둘 다 `rag_config.json.bak` 백업).
- **다운그레이드 주의**: v1.2.0에서 암호화된 키는 이전 버전이 읽지 못합니다. 이전 버전으로 돌아가면 설정에서 키를 다시 입력하세요.
- **설정 파일을 다른 PC로 복사**하면 암호화된 키는 복호화되지 않습니다(키 미설정으로 표시). 새 PC에서 키를 다시 입력하세요.
