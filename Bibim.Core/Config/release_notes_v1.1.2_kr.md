> **기능 릴리즈** — 자가 교정(self-correction) 도입 + 플래너 정확도 강화 + 대화 흐름 UX 정리 + 보안 1건.

## 한 줄 요약

**BIBIM이 이제 생성한 코드를 실제로 실행해보고, 런타임 오류나 0개 결과가 나오면 스스로 원인을 읽고 재생성한다. 더불어 "파라미터 값 입력"을 "파라미터 생성"으로 오인하던 플래너 버그를 잡고, 대화 흐름을 다듬고, 로그에 API 키가 평문으로 남던 문제를 막았다.**

## ⭐ 신규: 자가 교정 (Self-Correction)

기존엔 코드가 **컴파일만 되면** 통과였다. 이제는 컴파일 성공 후 dry-run으로 실제 실행까지 확인한다.

- **런타임 예외** 발생 → 예외 메시지를 LLM에 피드백해 **자동 재생성**
- **0개 요소** 결과(예: 대상이 안 잡힘) → 마찬가지로 원인 피드백 후 재생성
- **재생성은 1회로 제한**, 대규모 변경(영향 500개 초과)은 **스케일 가드**로 차단해 폭주 방지
- 컴파일 에러 재시도 루프와 동일한 구조 — 토큰 낭비 없이 직전 실패만 피드백

→ 첫 시도가 런타임에서 조용히 실패하던 작업이 사용자 개입 없이 한 번 더 자동 교정된다.

## 플래너 정확도

- **파라미터 값 입력 = 수정(EDIT)으로 정확히 분류**: "Comments에 reviewed 입력" 같은 요청에 바인딩/데이터타입/그룹/인스턴스-타입 **생성용 질문 4개를 띄우던 오분류 제거**. 값 입력은 절대 생성으로 분기하지 않음.
- **모델 식별자 자동 인식**: Level / Sheet / Phase / Workset을 결정론적으로 추출해 플래너에 주입 → 이름 매칭 실수 감소.

## 대화 흐름 UX

- 질문-답변 에코 정리, 불필요한 확인 게이트 제거, 라벨/피드백 메시지 개선 (9개 항목)
- 그래픽 동사 게이트, 첫 실행 환영 가이드, 경과 시간 타이머, i18n 보강

## 보안

- **로그 API 키 마스킹**: 키 저장 시 페이로드의 모든 provider 키(anthropic/openai/gemini/local 등)가 디버그 로그에 평문으로 남던 문제 차단.

## 인스톨러

- **버전 누락 방지**: 빌드 가드가 폴더 존재가 아니라 `RevitAPI.dll` 존재를 검사 — 제거 후 남은 잔재 폴더 때문에 빌드 전체가 실패하던 문제 해결.
- **설치 경로 분리**: 신규 설치 경로가 `...\BIBIM AI\Revit`로 변경 (타 BIBIM 제품과 공존).
- 설치 메시지 최신화(지원 버전 2022~2027 명시, 멀티 프로바이더 안내).
